PASS if the final message is the weekly report's result and all of these hold:
- the delivery is the link to the page (the same page as last week, now updated), with no claim
  that it was sent, emailed, posted or shared with anyone;
- it says what changed since last week and how last week's calls held (for example "act now"
  calls that held, as a count or a share);
- no weekly schedule is said to be set up or created: it may say the report is run by hand (for
  example "say 'update my trend report' next week") or offer a schedule as a question, but never
  as done without the user's yes.
FAIL if it says a message, email or notification was sent to anyone, if it gives a new or
different link than last week's page (a second page), or if it says a scheduled task was created.

The run's language is English; judge meaning, not exact wording.
