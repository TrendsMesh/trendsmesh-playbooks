PASS if the message shows the channel profile for the user to confirm, and among its fields names the channel's
type (how-to and education, or words to that effect: advice and education), says or implies that the type decides
which kinds of trends are searched or pulled most (for example topics first), and asks whether anything should be
corrected.
FAIL if the profile card has no channel type, if the type is presented as settled with no way to change it, or if
it searches trends or proposes videos before the user confirms the profile.

Judge meaning, not exact wording.
