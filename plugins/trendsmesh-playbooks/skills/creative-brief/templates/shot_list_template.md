# Template: creator shot list (PB2, check-in G4)

**The document a creator or operator takes to the shoot.** Written from an accepted concept brief (same `brief_id`). Plain language, one screen per shot; nothing the creator has to interpret.

---

## 1. At a glance
`brief_id`, the idea in one sentence, target length, formats to frame for (9:16 and/or 4:5, R6), shoot time estimate, deadline.

## 2. Casting and look
Who is on camera (age range, gender, look, energy), wardrobe, hair and make-up notes, what to avoid.

## 3. Location, light, props
Setting (room, time of day), light (natural / lamp, direction), props list with **the product and how it appears** (screen, cover, notebook…), set dressing.

## 4. Shots
| # | Beat (from the brief) | Framing and angle | Action | Line to say | Duration | Takes | Notes |
|---|---|---|---|---|---|---|---|
| 1 | hook | | | verbatim, then "own words" version with the must-say points | | ≥ 3 | first frame must already show … |
| … | | | | | | | |

Lines: natural delivery, not read out; the must-say points are listed under each line. Record each hook variant from the brief as a separate take.

## 5. Framing for both formats
Keep the subject and any action inside the central safe area so one take works for 9:16 and 4:5; leave headroom for on-screen text (top third) and UI (bottom 20%).

## 6. Sound on set
Room tone 10 s, lavalier or phone mic close, no music on set (music is added in the edit, licensed).

## 7. What to deliver
- Raw clips, original resolution and frame rate, **no captions, no filters, no music burned in**.
- Separate audio file if recorded separately.
- File names: `<brief_id>_shot<NN>_take<NN>.<ext>`.
- Where to upload, by when.

## 8. Before you send (checklist)
All shots and hook variants recorded · the product visible where the list says · lines cover the must-say points · clean files without captions · both formats framed.
